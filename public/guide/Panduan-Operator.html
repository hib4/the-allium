The Allium
Panduan Operator

Release candidate 1.1.0-rc.2 · Glitz Inclusive, Jakarta. Untuk uji lokasi, belum disahkan untuk konser. Demo dan alur sintetis diuji melalui perangkat lunak. Soundcraft Ui24R fisik, Windows ASIO, HDMI, serta kenyamanan audiens wajib diuji di lokasi.

Peralatan dan persiapan

Gunakan laptop dengan RAM minimal 8 GB (16 GB disarankan), layar eksternal 1920×1080, GPU yang mendukung WebGL, ruang kosong 1 GB, browser Chrome/Edge terbaru, adaptor daya, kabel USB-A/USB-C ke USB-B berkualitas, kabel HDMI dan adaptor yang sesuai. Ini rekomendasi awal; bukan jaminan performa laptop.

Paket yang dibangun saat ini: macOS ARM64 (Apple Silicon), hanya diuji pada Mac pengembangan. Mac Intel memerlukan paket terpisah. Windows 11 x64 merupakan target paket berikutnya; paket dan uji Windows masih menunggu mesin Windows. Jangan menjalankan paket Mac di Windows. Di Windows, instal driver multichannel resmi Soundcraft yang sesuai Ui24R sebelum acara. Siapkan installer dari halaman resmi Ui24R; kompatibilitas versi driver/Windows harus dikonfirmasi oleh teknisi venue. macOS menggunakan CoreAudio; pastikan izin mikrofon/audio input untuk aplikasi yang menjalankan layanan diberikan jika diminta.

Sediakan paket, browser, dan driver sebelum internet dimatikan. Aplikasi berjalan lokal; tidak membutuhkan internet setelah persiapan. Jangan ubah routing, gain, patch USB, atau konfigurasi mixer untuk aplikasi ini tanpa persetujuan teknisi audio venue.

Instalasi dan menjalankan

  1. Verifikasi versi dan checksum SHA-256 dengan teknisi yang memberikan paket. Ekstrak ZIP ke folder lokal yang dapat dibaca. Jangan jalankan langsung dari ZIP.
  2. Paket internal belum ditandatangani. Di Mac, bila diblokir, gunakan menu klik kanan → Open dan pengaturan Privacy & Security untuk membuka paket yang telah diverifikasi. Jangan menonaktifkan perlindungan sistem secara menyeluruh. Di Windows, kebijakan SmartScreen dapat memerlukan persetujuan teknisi; jangan gunakan paket yang tidak dikenal.
  3. Klik dua kali Start The Allium.command (Mac) atau Start The Allium.cmd (Windows setelah tersedia). Jendela layanan harus tetap terbuka. Browser membuka http://127.0.0.1:8765/control. Tidak perlu memasang Node.js atau Python.
  4. Pilih Demo, lalu Play demo. Pastikan gambar dan kontrol berfungsi sebelum menghubungkan mixer.
  5. Untuk menutup seluruh layanan, gunakan Stop The Allium, kemudian tutup tab display. Tombol Stop visualization hanya mengubah layar ke Standby.

Hubungkan Ui24R dan pilih perangkat

  1. Hubungkan port USB-B interface Ui24R ke laptop; jangan gunakan port USB-A untuk media rekaman. Aktifkan mixer dan tunggu perangkat terdeteksi.
  2. Di Operator desk, klik Refresh devices. Pada Capture device, pilih Ui24R dengan 32 input; Windows menggunakan ASIO, Mac menggunakan CoreAudio.
  3. Klik Apply input settings. Status layanan terhubung berbeda dari status input audio. Pastikan input menunjukkan connected.
  4. Buka All USB input meters. Minta pemain membunyikan satu instrumen pada satu waktu. Catat nomor USB yang aktif, termasuk semua mikrofon drum. Jangan menebak berdasarkan nama instrumen.

Referensi USB: 1–2 master stereo; 3–10 AUX 1–8; 11–32 input mixer 1–22. Nomor ini bukan penetapan instrumen venue. Jika patch aktual tidak menghasilkan kanal yang diharapkan, hubungi teknisi mixer; aplikasi tidak mengubah patch tersebut.

Penetapan instrumen dan sensitivitas

  1. Buka baris guitar, drums, piano, vocals (dan bass jika digunakan). Centang kanal USB yang sudah dibuktikan melalui meter.
  2. Untuk drum, centang beberapa kanal pada satu kelompok drums. Kanal yang ditetapkan ke dua instrumen akan membuat keduanya merespons sinyal yang sama; periksa pesan Shared assignments.
  3. Klik Apply input settings. Pilih Start Live. Periksa satu instrumen per giliran: gitar jalur melodi, drum pulsa, piano kelompok bunga/konstelasi, vokal pita, bass gelombang rendah.
  4. Jika terlalu lemah/kuat, sesuaikan Sensitivity dan simpan. Sesuaikan Noise threshold agar kebocoran/derau tidak terus memicu bentuk. Jangan menaikkan gain mixer hanya untuk visual.
  5. Pitch hanyalah perkiraan nada tunggal; gitar akor dan piano polifonik tidak dianalisis sebagai transkripsi not/akor. Aktivitas drum adalah perkiraan ritme.

Layar besar dan operasi acara

  1. Hubungkan HDMI, pilih mode desktop Extend, tetapkan display venue 1920×1080. Sambungkan daya laptop dan cegah sleep selama acara sesuai kebijakan venue.
  2. Klik Open display. Pindahkan jendela browser ke layar eksternal. Gunakan tombol fullscreen pada halaman display; Esc keluar fullscreen. Dashboard tetap di laptop.
  3. Gunakan profil browser yang sama untuk dashboard dan display; jangan gunakan Incognito/profil berbeda. Sinkronisasi bukan untuk laptop lain.
  4. Mulai dengan Standby, periksa caption dan Reduced motion, kemudian Start Live. Jika audio terputus, gambar masuk keadaan menunggu; aplikasi tidak otomatis mengganti ke Demo.
  5. Gunakan Stop visualization saat jeda. Input tetap tersedia untuk meter. Untuk selesai, jalankan Stop The Allium.

Tampilkan atau sembunyikan caption

Di Caption desk, matikan Show captions untuk menghilangkan seluruh area caption dari layar audiens dan preview. Visual mengisi ruang yang kosong. Teks caption tidak dihapus. Aktifkan kembali untuk menampilkan cue terbaru. Caption yang dikirim saat tersembunyi disimpan dan baru terlihat setelah Show captions aktif.

Simpan, pulihkan, dan laporkan masalah

Buka Settings backup and troubleshooting → Export settings. Simpan berkas bertanggal setelah soundcheck. Restore settings mengunduh cadangan terlebih dahulu, memulihkan pengaturan visual ke Standby, dan menghapus pilihan perangkat untuk keamanan. Pilih ulang perangkat, periksa kanal, lalu Apply input settings. Caption sementara tidak dilanjutkan. empty-config.json dapat diimpor sebagai awal kosong. illustrative-config-NOT-VENUE.json hanya contoh penetapan sintetis; jangan gunakan untuk konser tanpa mengidentifikasi ulang setiap kanal venue.

Rollback

Stop The Allium. Ekstrak paket versi sebelumnya ke folder lain dan jalankan launcher versi tersebut. Jangan menimpa paket yang sedang berjalan. Restore ekspor pengaturan versi yang kompatibel, pilih ulang perangkat, uji Demo lalu satu instrumen Live. Bila pengaturan rusak, teknisi dapat mencadangkan settings.json dan memulihkan settings.bak di folder data aplikasi. Simpan log serta paket bermasalah untuk laporan.
