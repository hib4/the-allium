The Allium
Panduan Operator

Release candidate 1.1.0-rc.2 · Glitz Inclusive, Jakarta. Untuk uji lokasi, belum disahkan untuk konser. Demo dan alur sintetis diuji melalui perangkat lunak. Perangkat USB venue, Windows ASIO, LED/HDMI, serta kenyamanan audiens wajib diuji di lokasi.

Peralatan dan persiapan

Gunakan laptop dengan RAM minimal 8 GB (16 GB disarankan), output LED 4416×896 dengan pemetaan processor yang benar, GPU yang mendukung WebGL, ruang kosong 1 GB, browser Chrome/Edge terbaru, adaptor daya, kabel USB-A/USB-C ke USB-B berkualitas, kabel HDMI dan adaptor yang sesuai. Ini rekomendasi awal; bukan jaminan performa laptop.

Paket yang dibangun saat ini: macOS ARM64 (Apple Silicon), hanya diuji pada Mac pengembangan. Mac Intel memerlukan paket terpisah. Windows 11 x64 merupakan target paket berikutnya; paket dan uji Windows masih menunggu mesin Windows. Jangan menjalankan paket Mac di Windows. Di Windows, instal driver input yang sesuai perangkat sebelum acara; pengujian native Windows masih diperlukan. Siapkan driver dari produsen perangkat; kompatibilitas driver/Windows harus dikonfirmasi oleh teknisi venue. macOS menggunakan CoreAudio; pastikan izin mikrofon/audio input untuk aplikasi yang menjalankan layanan diberikan jika diminta.

Sediakan paket, browser, dan driver sebelum internet dimatikan. Aplikasi berjalan lokal; tidak membutuhkan internet setelah persiapan. Jangan ubah routing, gain, patch USB, atau konfigurasi mixer untuk aplikasi ini tanpa persetujuan teknisi audio venue.

Pembaruan mix USB: paket portabel lama belum memuat perubahan ini. Teknisi harus membangun ulang dari source terbaru dan menguji paket sebelum dipakai. Hasil uji perangkat venue/LED belum dikonfirmasi; lihat docs/audio-setup.md.

Instalasi dan menjalankan

  1. Verifikasi versi dan checksum SHA-256 dengan teknisi yang memberikan paket. Ekstrak ZIP ke folder lokal yang dapat dibaca. Jangan jalankan langsung dari ZIP.
  2. Paket internal belum ditandatangani. Di Mac, bila diblokir, gunakan menu klik kanan → Open dan pengaturan Privacy & Security untuk membuka paket yang telah diverifikasi. Jangan menonaktifkan perlindungan sistem secara menyeluruh. Di Windows, kebijakan SmartScreen dapat memerlukan persetujuan teknisi; jangan gunakan paket yang tidak dikenal.
  3. Klik dua kali Start The Allium.command (Mac) atau Start The Allium.cmd (Windows setelah tersedia). Jendela layanan harus tetap terbuka. Browser membuka http://127.0.0.1:8765/control. Tidak perlu memasang Node.js atau Python.
  4. Pilih Demo, lalu Play demo. Pastikan gambar dan kontrol berfungsi sebelum menghubungkan mixer.
  5. Untuk menutup seluruh layanan, gunakan Stop The Allium, kemudian tutup tab display. Tombol Stop visualization hanya mengubah layar ke Standby.

Uji lokal dengan mikrofon MacBook

Jalankan npm run audio dan npm run dev di dua terminal. Buka http://localhost:5173/control. Pilih secara eksplisit MacBook Pro Microphone → Mono → Input 1 → Auto, Apply, lalu Start Live. Izinkan mikrofon untuk host Python melalui Privacy & Security; izin browser tidak sama dengan izin Python.

Periksa RMS/Peak mentah, format aktual, Frames fresh, dan Capture age. Meter tetap bergerak bila sinyal berada di bawah ambang visual. Coba suara bicara, tepukan terpisah, musik dari speaker eksternal, dan jeda tenang. Catat sumber suara yang benar-benar diuji. Keheningan saja tidak membuktikan izin ditolak. Standby/Live tidak merestart capture; USB venue dapat dipilih kemudian dengan alur yang sama.

Hubungkan mix USB dan pilih perangkat

  1. Hubungkan perangkat audio USB ke MacBook Pro M4. Konfirmasikan dengan teknisi bahwa mix gabungan venue masuk ke kanal USB yang benar. Aktivitas di System Settings belum membuktikan Python memiliki izin input.
  2. Izinkan mikrofon untuk aplikasi atau terminal yang menjalankan Python melalui System Settings → Privacy & Security → Microphone. Mulai ulang host bila diperlukan.
  3. Klik Refresh devices, lalu pilih Capture device. Perangkat mono, stereo, dan multichannel didukung; tidak wajib 32 kanal atau 48 kHz.
  4. Pilih Mono dan kanalnya, atau Stereo dan kanal kiri/kanan yang berbeda. Nomor Input adalah posisi kanal perangkat, bukan nama instrumen. Mix pada kanal 11–12 dapat dipilih langsung.
  5. Gunakan Sample rate → Auto untuk mengutamakan rate bawaan perangkat; atau pilih rate yang telah diperiksa. Klik Apply input settings. Periksa Actual capture dan meter input. Format pilihan diperiksa kembali ketika capture dibuka.

Respons visual mix gabungan

Klik Start Live. Low currents mengikuti energi rendah; Mid flowing lines energi tengah; High filaments energi tinggi/perubahan spektral; Transient blooms mengikuti perubahan serangan musik. Lapisan ini tidak mengenali instrumen. Nilai nol menyembunyikan lapisan. Demo tetap menggunakan enam bahasa visual instrumen yang terpisah.

Sesuaikan Sensitivity dan Noise threshold, kemudian Apply. Sensitivitas tidak mengubah gain mixer. Input terhubung tetapi sunyi adalah keadaan sehat; tidak ada irama simulasi sebagai pengganti. CLIP harus dilaporkan kepada teknisi audio.

LED 4416 × 896 dan operasi acara

  1. Hubungkan LED processor sebagai desktop Extend. Teknisi harus mengonfirmasi pemetaan output aktif 4416 × 896 tanpa overscan.
  2. Pilih Display profile → Venue LED · 4416 × 896. Rasio tepatnya 69:14; pada layar berbeda komposisi ditampilkan proporsional. Profil Responsive dapat digunakan untuk layar lain.
  3. Klik Open display, pindahkan browser ke output LED, lalu masuk fullscreen. Gunakan URL dan profil browser yang sama dengan dashboard. Esc dan tombol exit tetap tersedia.
  4. Aktifkan Display calibration. Pastikan semua sudut/batas terlihat, garis tengah benar, dan lingkaran tidak oval. Matikan sebelum pertunjukan. Overlay tidak mengubah capture atau pengaturan caption.
  5. Mulai dari Standby, periksa caption dan Reduced motion, lalu Start Live. Stop visualization hanya menghentikan respons visual; capture dan meter tetap berjalan. Live dapat dilanjutkan tanpa restart layanan.
  6. Jika USB terputus, aplikasi menampilkan status menunggu dan mencoba perangkat yang sama kembali. Tidak ada perpindahan otomatis ke mikrofon lain atau Demo. Untuk selesai, gunakan Stop The Allium.

Tampilkan atau sembunyikan caption

Di Caption desk, matikan Show captions untuk menghilangkan seluruh area caption dari layar audiens dan preview. Visual mengisi ruang yang kosong. Teks caption tidak dihapus. Aktifkan kembali untuk menampilkan cue terbaru. Caption yang dikirim saat tersembunyi disimpan dan baru terlihat setelah Show captions aktif.

Simpan, pulihkan, dan laporkan masalah

Buka Settings backup and troubleshooting → Export settings. Simpan berkas bertanggal setelah soundcheck. Restore settings mengunduh cadangan terlebih dahulu, memulihkan pengaturan visual ke Standby, mematikan kalibrasi, dan menghapus pilihan perangkat/kanal untuk konfirmasi ulang. Pilih ulang perangkat, periksa kanal, lalu Apply input settings. Caption sementara tidak dilanjutkan. empty-config.json dapat diimpor sebagai awal kosong. illustrative-config-NOT-VENUE.json hanya contoh mix sintetis. Ekspor lama tetap dapat dibaca tetapi kanal mix harus dipilih ulang; jangan menebak kanal dari penetapan instrumen lama.

Rollback

Stop The Allium. Ekstrak paket versi sebelumnya ke folder lain dan jalankan launcher versi tersebut. Jangan menimpa paket yang sedang berjalan. Restore ekspor pengaturan versi yang kompatibel, pilih ulang perangkat, uji Demo lalu mix Live. Bila pengaturan rusak, teknisi dapat mencadangkan settings.json dan memulihkan settings.bak di folder data aplikasi. Simpan log serta paket bermasalah untuk laporan.
